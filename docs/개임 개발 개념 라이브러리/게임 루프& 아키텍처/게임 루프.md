# 게임루프
- 게임 루프란 입력이 있든 없든 스스로 계속 도는 반복문 이것이 게임 루프(Game Loop)입니다.


## 무엇을
- 게임 루프를 입력, 갱신, 렌더링을 프레임(한 바퀴)로 표현한 것이다.
- 입력은 이벤트로 만들어줘
- 갱신은 delta time 표현하도록 구성해라
- 화면을 그려줘(render)

## 무슨 문제가 발생했나요?
- 인게임에서의 마우스 커서가 실제 커서의 움직임과 동일하지 않았다.
- 적들의 수가 너무 많았다.
- 적들을 잡기가 너무 어려웠다.

## 왜
- 모르겠다.
- 적들의 최대 수를 지정하지 않았다.
- 적들의 HP를 설정하지 않았다.

## 실습
- 게임 루프, 용어들을 총동원해서 게임을 만드셔야 합니다.
