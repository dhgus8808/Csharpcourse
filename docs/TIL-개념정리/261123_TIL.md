# AI게임개발 실습

- 수업 내용 정리.
   1>AI게임개발 실습
   깃은 작성한 문서의 버전을 관리하는 역할을 수행하고 깃허브는 만든 코드들을 저장하는 저장소의 역할을 수행한다

```CSharp

 // Dino Game의 루프함수
 
 private void GameLoop()
{
    while (!isGameOver)
    {
        HandleInput();
        UpdatePhysics();
        UpdateObstacles();
        CheckCollision();
        Render();

        score++;
        if (score > highScore) highScore = score;

        // 점수가 오를수록 게임 속도 빨라짐 (최소 딜레이 25ms)
        int delay = Math.Max(25, 50 - (score / 150));
        Thread.Sleep(delay);
    }
}
```
