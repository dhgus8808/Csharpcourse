# 깃을 통한 프로젝트 관리

- 수업 내용 정리.
   1>깃과 깃허브
   깃은 작성한 문서의 버전을 관리하는 역할을 수행하고 깃허브는 만든 코드들을 저장하는 저장소의 역학을 수행한다
   2>깃을 올리는 과정 설명.
   
 3> 로컬과 리모트 / 이 사이에 파일의 흐름 이해했는가
   로컬은 내 컴퓨터에 저장되어 있는 문서를 올리는거고 리모트는 웹에서 내 컴퓨터에 있는 문서를 원격으로 가져오는 것

  [육하원칙]
- 누가 깃을 쓰는가?
   컴퓨터를 사용해서 문서작업을 하는 모든 사람들
- 왜 쓰는가?
  서류를 수정한 버전으로 쉽게 되돌릴 수 있어서
- 언제 쓰면 좋을까?
  
- 어디에서 활용되고 있을까?
  컴퓨터로 문서작업을 하는 모든 직종

  [힌트: ‘오늘 배운 것’ 대신 언제 무엇이 잘못됐는가]
- 상황·환경·입력·문제: ____
  [힌트: 독자가 같은 출발점을 만들 수 있게]
- 가설·시도·관찰 결과: ____
  [힌트: 실패도 포함하되 실제 수행한 내용만]
- 해결·원인·검증 증거: ____
  [힌트: 무엇을 바꿨고 같은 조건에서 무엇이 달라졌나]
- 교훈·적용 한계·다음 확인: ____
  [힌트: 다음 사람이 취할 행동으로]
